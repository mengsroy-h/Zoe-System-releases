# ZoeW — APK Android ផ្លូវការ

> Repository នេះមានតែ **Release** (ឯកសារ APK ចុះហត្ថលេខារួច) របស់ App ZoeW សម្រាប់ Android ប៉ុណ្ណោះ។
> មិនមាន source code ទេ — source code ជាកម្មសិទ្ធិឯកជនរបស់ម្ចាស់ (មើល «អាជ្ញាប័ណ្ណ»)។

## កំណែ

កំណែចុងក្រោយនៅទំព័រ **[Releases](../../releases/latest)**។ ឈ្មោះ Release `zoew-android-v<កំណែ>` · ឯកសារ `ZoeW-<កំណែ>.apk` និង
`ZoeW-<កំណែ>.apk.sha256`។ Release នីមួយៗបង្កើតដោយស្វ័យប្រវត្តិពី workflow build របស់ ZoeW ហើយចុះហត្ថលេខាដោយ keystore ផ្លូវការតែមួយ។

## មុខងារ

- **ចែក APK** ៖ ទាញ APK ដំឡើងដោយផ្ទាល់លើទូរស័ព្ទ Android (មិនឆ្លងកាត់ Play Store)។
- **Update ក្នុង App** ៖ App ZoeW ដែលដំឡើងរួច ពិនិត្យ Release នៅទីនេះដោយខ្លួនឯង ➜ 🔔 ➜ «📥 ទាញយក និងដំឡើង APK» ➜ ទាញ និងដំឡើងក្នុង App (ទិន្នន័យ · PIN · Activation នៅដដែល)។
- **ផ្ទៀងផ្ទាត់** ៖ ឯកសារ `.sha256` សម្រាប់ផ្ទៀងថា APK ដែលទាញបានមិនខូច និងមិនត្រូវបានកែ។

## របៀបប្រើប្រាស់

1. បើក **Releases** ➜ ជ្រើស Release ចុងក្រោយ ➜ ទាញ `ZoeW-<កំណែ>.apk`។
2. បើកឯកសារលើទូរស័ព្ទ Android ➜ អនុញ្ញាត «ដំឡើងពីប្រភពនេះ» (លើកដំបូង) ➜ ដំឡើង។
3. មាន ZoeW Android រួចហើយ ➜ ដំឡើងជាន់បានផ្ទាល់ — ទិន្នន័យ · PIN · Activation Key នៅដដែល។
4. ផ្ទៀងផ្ទាត់ (ស្រេចចិត្ត) ៖ `sha256sum ZoeW-<កំណែ>.apk` ត្រូវស្មើតម្លៃក្នុង `ZoeW-<កំណែ>.apk.sha256` និងក្នុងកំណត់ចំណាំ Release។

⛔ បើទូរស័ព្ទរាយ «App not installed» ➜ App ដែលមានស្រាប់ត្រូវ sign ដោយ keystore ផ្សេង (ឧ. build ពី Android Studio) ➜ ទាក់ទងអ្នកលក់មុនលុប App ចាស់ (កៅអី License ចងនឹងឧបករណ៍)។

## ប្រព័ន្ធសុវត្ថិភាព

- APK ទាំងអស់ sign ដោយ **keystore ផ្លូវការតែមួយ** ➜ Android បដិសេធការដំឡើង APK ដែល sign ដោយ keystore ផ្សេងជាន់ App នេះ។
- App ផ្ទៀងផ្ទាត់ package និងលេខកំណែរបស់ APK ដែលទាញបាន មុនបើកផ្ទាំងដំឡើង។
- ទាញ APK តែពី repository នេះ ឬពីអ្នកលក់ផ្ទាល់ — កុំដំឡើង APK ពីប្រភពផ្សេង។
- ការប្រើ App ត្រូវការ **Activation Key** ឬគណនីហាងពីអ្នកលក់ — APK តែឯងមិនផ្តល់សិទ្ធិប្រើប្រាស់ទេ។
